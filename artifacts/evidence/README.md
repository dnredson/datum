pre-deployment checkpoint; its false deployment/publication flags are historical.
The subsequent `reconcile-first.json` and `reconcile-second.json` document deployment
and convergence. They retain selected non-secret fields from the original reports.

These files are evidence, not executable authorization or current host state.
`validation.json` describes the local tests at this checkpoint.
